## 구현한 것

공식 CUA 실행 앞에 독립 호스트와 MCP 전달기를 추가했다. 공식 설치에 포함된
Node를 재사용하므로 별도 npm 설치가 필요하지 않다. Rust 운영 코드와 기존
공식 패키지는 수정하지 않았다.

호스트는 실행할 때마다 자체 키와 실행 식별자를 생성한다. 자신의 MCP 자식으로
전달 중인 실제 `js` 호출의 대화·턴 정보와 일치할 때만 연결을 허용한다. 다른
대화·턴·실행 식별자, 완료·취소·만료된 호출은 허용하지 않는다. 모델이 작성한
도구 인수에 넣은 정보는 권한으로 사용하지 않는다.

사이트·작업 승인은 공식 도구가 계속 담당한다. 전달기는 승인 요청과 응답을
그대로 전달하며, 허용 응답을 만들거나 공식 가드를 제거하지 않는다. 이번
호스트의 소유권 확인 응답과 사이트 접근 승인은 별개의 단계다.

변경 파일은 `experiments/browser-host`의 호스트, 실행기, 회귀 시험, 실제 턴
검증기 및 README다. 기존 봇·MCP 수명 분리나 미러 전송 수정은 이 변경에 섞지 않았다.

## 종료 시험 중 발생한 문제와 복원

GPT 앱 트리를 종료할 때 그 아래에서 실행됐던 Chrome도 함께 종료됐다.
Chrome을 보호 대상으로 먼저 분리하지 않은 시험 진행 실수다. 이 사실을 사용자에게
알렸고, 같은 현주 프로필을 별도로 실행했다. 이전에 관측한 정확한 검색 URL을
공식 도구로 다시 열고 유지 표시하여 기존 검색 탭을 복원했다. 기존 페이지의
휘발성 내부 상태까지 복원했다고 주장하지 않는다.

복원된 검색 탭은 `1340769678`이며, 빈 탭 `1340769620`도 보존했다.
이후 최종 시험에서는 두 탭을 건드리지 않았다. 앞으로 앱 종료 시험은 프로세스
트리에 포함된 사용자 브라우저를 먼저 별도 보호 대상으로 확인해야 한다.

## 검수 범위와 남은 작업

정해진 시험과 짧은 추가 코드 검수를 수행했고, 발견한 환경변수 혼합 및 종료
처리 문제를 수정한 최종 소스로 다시 시험했다. 시제품 범위에서 추가로 확인된
차단 결함은 없다. 이것은 Pro 검수·전체 제품 승인·운영 배포 승인이 아니다.

운영용 Rust 실행 경로 연결과 배포 묶음 포함은 아직 구현하지 않았다. 이 단계에서는
명시적인 시험 실행 경로만 제공한다. Windows 파이프의 명시적 peer 검증,
다른 사용자 계정 접근 시험, 실제 승인 거절 상황의 종단 검증, 긴 작업·강제
부모 종료·업데이트 호환성 검증도 운영 적용 전에 남아 있다. 구현 프로토콜은
설치된 도구 버전에 맞춘 것이므로 향후 공식 패키지 변경 시 재검증해야 한다.

원래 목표 중 **자체 호스트 구현과 공식 확장 연결·앱 종료 후 실제 조작 가능성**은
이번 시험으로 확인했다. 모든 사이트·기능의 GPT 앱 동등성이나 이미 운영 봇에서
사용 중이라는 의미로 확대 해석하면 안 된다.
